# 📚 Library Management API

## 🔍 Project Overview

This is a RESTful API built with **Node.js**, **Express**, and **MySQL** to manage a basic library system.  
The system is designed for student users who can find, borrow, use, and return books.  
It includes course-based book preferences to help students access recommended resources.

---

## 🧩 Features

- 📘 Manage Students, Courses, Books, and Book Copies
- 🔁 Record Book Borrowing and Returning
- 🎯 CRUD operations for all major entities
- 🧠 Book preferences based on student courses

---

## 🛠️ Technologies Used

- **Node.js + Express** (Backend API)
- **MySQL** (Database)
- **mysql2** (MySQL client for Node.js)
- **Nodemon** (for development)
